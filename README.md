## 製品概要
### 背景(製品開発のきっかけ）
友人の悩みの相談や辛い状況などを聞いていると日常の些細な事もストレスになっていることが分かった。
そこから調べると日常生活の些細なストレスが心の大きな負担になることがわかった。
その解決策を模索する中でストレスを他の楽しいことで相殺、上書きすることはあってもストレスそのものにアプローチして解決していないとわかった。
そしてストレスそのものにアプローチする方向性で考え、育成ゲーム本来のストレス緩和とストレスが育成につながることで従来の育成ゲームよりもストレスが軽減されるのではないかと考え、開発することにしました。

### 製品説明（具体的な製品の説明）
今回の私たちのテーマは、ストレス×Techです。
日常でストレスを感じることありますよね。このストレス社会で、嫌なことや辛いことを乗り越えながら生きていくあなたをサポートしたい。
このアプリが行うことは「心理をハックし、ストレス社会に挑む」ことであり、ターゲットは日常でストレスを感じたことがあるすべての人です。
以下はそれを実現するためのアプローチです。

①育成ゲームの楽しさによる継続の促進
②作り出す雰囲気、世界観による安心できる場所という価値の創造
③自分のストレスに向き合う場所を提供すると言う価値の創造
④自分の過去のストレスデータを分析して自分を見つめ直すきっかけになるヘルスケア的な自己管理の機会の提供


### 特長
#### 1. ストレスが成長に繋がる育成ゲーム
このゲームのメイン機能であり、独自性でもある。
感じたストレスがキャラクターの成長に繋がることで「ストレスが発生する、ゲームにストレスを吐き出す、キャラクターが育つ、ストレスが軽減される」流れを構築することで問題の解決を図ります。

#### 2. ストレスを吐き出す仕組み
私たちはこのゲームを開発する上で「自分の吐き出したいストレスが見当たらない」「ストレスを吐き出す手順がめんどくさい」こういったことでプレイヤーがストレスを感じるのは本末転倒だと考えました。
そのためストレスを自分で入力できる仕組みとよく記入するストレスをピン止めできる仕組みを構築しました。

#### 3. キャラクターの会話の柔軟性
キャラクターの会話に定型文とは異なる柔軟性を持たせるようにしました。
こうすることでプレイヤー側に寄り添えるようにし、ストレスの軽減と愛着を抱きやすいようにしています。


### 解決出来ること
日常生活の些細なストレスが蓄積すると心の大きな負担になります。
そこで「ストレスが発生する、ゲームにストレスを吐き出す、キャラクターが育つ、ストレスが軽減される」この流れを構築し、些細なストレスを溜め込まないようにすることで心の負担の軽減を図ります
