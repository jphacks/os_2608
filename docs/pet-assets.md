# ペットの絵を差し替える手順

いまのペットの絵は、動作確認用の仮の絵です。本番の絵ができたら、同じ名前のファイルを置き換えるだけで反映されます。

## ファイルの置き場所と名前

置き場所: `src/assets/pet/`

| ファイル名 | 内容 |
| --- | --- |
| `lv1-normal.png` | レベル1・通常 |
| `lv1-happy.png` | レベル1・喜ぶ |
| `lv1-worried.png` | レベル1・心配する |
| `lv1-rest.png` | レベル1・休む／眠る |
| `lv2-…` / `lv3-…` | レベル2・3も同じ4種類 |

- 形式: 透明背景の PNG、**32 × 32 px**
- 同じ名前の `.png` があれば、仮の `.svg` より優先して使われます。仮の `.svg` は消しても消さなくても構いません。
- 表情の絵が無いときは、そのレベルの `normal` が代わりに表示されます。最初は `lv1-normal.png` などの通常絵だけでも動きます。
- レベル間で、足元と中心の位置をそろえてください。

## 置き換え方

絵のファイルを Claude に渡してもらえれば、こちらで配置して PR を作ります。
自分で置く場合は、GitHub の `src/assets/pet/` を開き、**Add file** → **Upload files** でアップロードしてください（`main` に直接ではなく、新しいブランチで PR を作る選択肢を選んでください）。
