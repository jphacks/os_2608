# お部屋の絵を差し替える手順

いまのお部屋の背景は、動作確認用の仮の色です。本番の絵ができたら差し替えます。

## 仕組み

- お部屋の一覧は `src/rooms.ts` にあります（名前と、開く「なかよしレベル」）。
- 背景は `src/index.css` の `.room-1` `.room-2` `.room-3` で指定しています。

## 差し替え方

絵のファイルと、部屋の名前・枚数を Claude に伝えてください。こちらで配置して PR を作ります。
自分で置く場合は、PNG を `src/assets/rooms/` に置き、`.room-N` の `background` を画像に書き換えてください（部屋を増やすときは `src/rooms.ts` にも1行足します）。

- 形式: PNG。ペットの絵と同じく、整数倍で拡大してもぼやけない大きさ（例: 160 × 120 px）がおすすめです。
